# Chandan Kumar Kisku — Portfolio

A responsive personal portfolio built with HTML5, CSS3 and a small amount of vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code's Live Server extension.
3. No build tools or package installation are required.

## Personalise before publishing
- Replace the placeholder GitHub links in the Projects section with your actual repository URLs.
- Replace the LinkedIn and GitHub profile links in the Contact section with your profile URLs.
- If you want a real profile photo, replace the `CK` avatar in `index.html` with an `<img>` element and add your image file.
- Review the education, skills and project descriptions to ensure every detail matches your latest experience.

## Publish with GitHub Pages
Create a GitHub repository, upload `index.html`, `style.css`, `script.js` and this README, then open **Settings → Pages** and select the `main` branch and `/ (root)` folder.
